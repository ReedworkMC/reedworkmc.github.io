## Hi, I'm 0kAj! 👋

I'm the developer behind **ReedworkMC** — an open-source project focused on Minecraft development.

My goal is to create useful tools, libraries and frameworks that make developing Minecraft plugins easier, cleaner and more enjoyable. Especially for developers working with **Java and PaperMC**.

Instead of keeping these projects to myself, I want to build them openly and make them available to everyone. You can explore the source code, use the projects, share ideas, report bugs or contribute your own improvements.

**ReedworkMC is my place to create, share and improve tools for the Minecraft developer community.**

## Made for Minecraft Developers

Minecraft plugin development should be enjoyable, not unnecessarily complicated.

That's why I'm working on tools that help developers focus on what matters: building great plugins and creating experiences for Minecraft servers.

My main focus is the Java ecosystem around **PaperMC**, but some of the libraries and utilities are designed to be useful beyond Minecraft as well.

## Built Openly, Built Together

ReedworkMC is an open-source development project. I want others to be able to participate, improve existing projects and bring their own ideas to the table.

You don't need to be an experienced developer to get involved. Bug reports, suggestions, documentation improvements and code contributions are all welcome.

Tools should be accessible. I publish my projects openly so developers can inspect, use and improve them.

### Minecraft Community

Minecraft has an amazing developer community. I want to contribute to it by creating useful tools and giving others the opportunity to help shape them.
