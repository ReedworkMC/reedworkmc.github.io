## 1. Overview

ReedworkMC is a privately maintained, non-commercial open-source project focused on tools, libraries, and frameworks for Minecraft and PaperMC development.

This website provides documentation and information about ReedworkMC and its projects, including Reedwork, ReedworkConfig, and ReedworkUtils.

The website is operated as a static documentation website and does not provide user accounts, contact forms, comments, or other built-in features intended to collect personal information from visitors.

ReedworkMC does not intentionally collect or store personal information through the functionality of this website.

## 2. Hosting by GitHub Pages

This website is hosted using GitHub Pages, a static website hosting service provided by GitHub.

When you visit this website, GitHub processes technical information associated with your request. According to GitHub, visitor IP addresses are logged and stored for security purposes, regardless of whether visitors are signed in to GitHub.

GitHub may also process additional technical information necessary to operate, maintain, and secure its services.

ReedworkMC does not operate or control GitHub's hosting infrastructure and does not independently determine how GitHub processes this technical information.

The processing of personal data by GitHub is governed by GitHub's own privacy policies.

For more information, see the [GitHub General Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

For information about GitHub's other legal and privacy policies, see the [GitHub Site Policy documentation](https://docs.github.com/en/site-policy).

## 3. No Analytics or Advertising

This website does not intentionally use:

- Google Analytics
- Advertising networks
- Tracking pixels
- Third-party analytics services
- User profiling
- Analytics or advertising cookies

No analytics or advertising system is operated by ReedworkMC on this website.

GitHub may nevertheless process technical information as part of operating and securing GitHub Pages. This processing is described in GitHub's own privacy documentation.

## 4. External Links

This website contains links to external websites and services, including GitHub and PaperMC.

When you follow an external link, you leave the ReedworkMC website. The respective external service may process personal data according to its own privacy policy and terms.

ReedworkMC has no control over the data processing practices of external services.

### 4.1. GitHub

ReedworkMC uses GitHub for source code hosting, issue tracking, releases, collaboration, and related project services.

This includes the ReedworkMC GitHub organization, its project repositories, examples, and the repository containing the source code of this website.

When you visit or interact with GitHub repositories or other GitHub services, GitHub processes information according to its own policies.

For more information, see the [GitHub General Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement) and the [GitHub Site Policy documentation](https://docs.github.com/en/site-policy).

### 4.2. PaperMC

ReedworkMC provides tools and resources for Minecraft and PaperMC development. This website may contain links to PaperMC documentation and other PaperMC resources.

When you visit or interact with PaperMC services, those services operate under their own privacy policies and terms.

## 5. Cookies

This website does not intentionally set cookies for analytics, advertising, or user tracking.

GitHub may use technically necessary cookies or similar technologies as part of providing and securing its services. Such processing is governed by GitHub's own policies.

## 6. Changes to this Privacy Policy

This Privacy Policy may be updated when the website, its functionality, the services used to operate it, or applicable legal requirements change.

The date of the latest revision is stated at the beginning of this Privacy Policy.
