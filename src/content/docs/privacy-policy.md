**Last updated:** August 28, 2026

## 1. Overview

Reedwork is a free and open-source project for PaperMC plugin development.

This website provides documentation and information about the Reedwork framework. It is operated as a static documentation website and does not provide user accounts, contact forms, comments, or other features intended to collect personal information from visitors.

Reedwork itself does not intentionally collect personal information through the functionality of this website.

## 2. Hosting by GitHub Pages

This website is hosted using GitHub Pages, a static website hosting service provided by GitHub.

When you visit this website, GitHub processes technical information associated with your request. According to GitHub, this includes the visitor's IP address, which is logged and stored for security purposes.

GitHub may also process other technical information necessary to operate, maintain, and secure its services.

The processing of personal data by GitHub is governed by GitHub's own privacy policies.

For more information, see the [GitHub General Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

For information about GitHub's other legal and privacy policies, see the [GitHub Site Policy documentation](https://docs.github.com/en/site-policy).

## 3. No Analytics or Advertising

This website does not use:

- Google Analytics
- advertising networks
- tracking pixels
- third-party analytics services
- user profiling
- analytics or advertising cookies

No analytics or advertising system is operated by Reedwork on this website.

GitHub may nevertheless process technical information as part of operating and securing GitHub Pages. This processing is described in GitHub's own privacy documentation.

## 4. External Links

This website contains links to external websites and services, including GitHub and PaperMC.

When you follow an external link, you leave the Reedwork website. The respective external service may process personal data according to its own privacy policy and terms.

Reedwork has no control over the data processing practices of external services.

### 4.1. GitHub

Reedwork uses GitHub for source code hosting, issue tracking, releases, collaboration, and related project services.

When you interact with the Reedwork GitHub repositories or other GitHub services, GitHub processes information according to its own policies.

For more information, see the [GitHub General Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement) and the [GitHub Site Policy documentation](https://docs.github.com/en/site-policy).

### 4.2. PaperMC

Reedwork is a framework for PaperMC plugin development, and this website may contain links to PaperMC documentation and other PaperMC resources.

When you visit or interact with PaperMC services, those services operate under their own privacy policies and terms.

## 5. Cookies

The Reedwork website does not intentionally set non-essential cookies.

GitHub may use technically necessary cookies or similar technologies as part of providing its services. Such processing is governed by GitHub's own policies.

## 6. Changes to this Privacy Policy

This Privacy Policy may be updated when the website, its functionality, the services used to operate it, or applicable legal requirements change.

The date of the latest revision is stated at the beginning of this Privacy Policy.
