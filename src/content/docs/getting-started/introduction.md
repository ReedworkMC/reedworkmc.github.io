# Reedwork

Reedwork is a modern framework for building PaperMC plugins with less
boilerplate.

It provides automatic component discovery, dependency injection,
event registration, annotation-based commands, custom enchantment
registration, and more.

## Why Reedwork?

Paper plugins often require a significant amount of repetitive
registration and setup code.

Reedwork aims to move that work out of your plugin code so you can
focus on the actual functionality of your plugin.

## What Reedwork provides

- Dependency Injection
- Automatic event registration
- Annotation-based commands
- Brigadier integration
- Automatic parameter resolution
- Custom enchantment registration
- Developer utilities
