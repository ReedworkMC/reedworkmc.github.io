# Install Reedwork

Reedwork is a Java framework for building PaperMC plugins with automatic component discovery, dependency injection, command generation, event registration, and custom Minecraft registry integration.

This guide explains how to add Reedwork as a dependency to an existing Paper plugin project.

## Requirements

Before installing Reedwork, make sure your project already has:

- a working PaperMC plugin project
- Java support matching your Paper version
- a build system using Maven or Gradle

Reedwork is distributed as a JAR file through GitHub Releases.

## Download Reedwork

The latest Reedwork release is **{version}**.

<a href={downloadUrl}>Download {jarName}</a> or visit the [GitHub Releases](https://github.com/ReedworkMC/Reedwork/releases/latest) page.

## Recommended installation: Maven local repository

<Badge text="Recommended" variant="note" />

The recommended installation method is adding Reedwork to your local Maven repository.

This keeps the Reedwork JAR separate from your plugin source code and allows Maven and Gradle to resolve the dependency using standard coordinates.

Install the downloaded JAR:

<Steps>
1.
    Download the latest Reedwork JAR.

2.
    Install the file into your local Maven repository:

    <Code lang="bash" code={`
mvn install:install-file \
    -Dfile=<PATH_TO_DOWNLOADED_JAR>/${jarName} \
    -DgroupId=dev.reedworkmc \
    -DartifactId=reedwork \
    -Dversion=${version} \
    -Dpackaging=jar
`}
    />

    Maven stores the artifact in your local repository, normally:

    <Code lang="text" code={`
    ~/.m2/repository
    `} />

    After installation, the downloaded JAR is no longer required.

3.
    Add Reedwork as a dependency.

    <AstroTabs>
        <AstroTabItem label="Maven" icon="mdi:console">

    Add the dependency to `pom.xml`:

            <Code lang="xml" code={`
    <dependency>
        <groupId>dev.reedworkmc</groupId>
        <artifactId>reedwork</artifactId>
        <version>${version}</version>
    </dependency>`}
            />
        </AstroTabItem>

        <AstroTabItem label="Gradle Groovy" icon="mdi:console">
            Ensure `mavenLocal()` is available:

            <Code lang="groovy" code={`
    repositories {
        mavenLocal()
    }

    dependencies {
        implementation "dev.reedworkmc:reedwork:${version}"
    }`}
            />

            `mavenLocal()` allows Gradle to resolve the Reedwork artifact from the local Maven repository.
        </AstroTabItem>

        <AstroTabItem label="Gradle Kotlin DSL" icon="mdi:console">
            Ensure `mavenLocal()` is available:

            <Code lang="kotlin" code={`
    repositories {
        mavenLocal()
    }

    dependencies {
        implementation("dev.reedworkmc:reedwork:${version}")
    }`}
            />

            `mavenLocal()` allows Gradle to resolve the Reedwork artifact from the local Maven repository.
        </AstroTabItem>
    </AstroTabs>

</Steps>

## Legacy installation: include the JAR in your project

<Badge text="Legacy" variant="caution" />

The legacy approach stores the Reedwork JAR directly inside your plugin project.

This method can be useful when the dependency should be bundled with the project structure.

However, the Maven repository installation is preferred for normal development.


<Steps>
1.
    Download the latest Reedwork JAR.


2.
    Place the downloaded JAR into your plugin project:

    <FileTree>
        - my-plugin
            - libs
                - {jarName}
            - src
                - ...
            - ...
    </FileTree>

3.
    Add the dependency configuration:

    <AstroTabs>
        <AstroTabItem label="Maven" icon="mdi:console">

            Add a system dependency:

            <Code lang="xml" code={`
    <dependency>
        <groupId>dev.reedworkmc</groupId>
        <artifactId>reedwork</artifactId>
        <version>${version}</version>
        <scope>system</scope>
        <systemPath>\${project.basedir}/libs/${jarName}</systemPath>
    </dependency>`}
            />

            The JAR must be located at `libs/{jarName}` relative to the project root.
        </AstroTabItem>

        <AstroTabItem label="Gradle Groovy" icon="mdi:console">

            Add the local file dependency:

            <Code lang="groovy" code={`
    dependencies {
        implementation(files("libs/${jarName}"))
    }`}
            />

            The JAR must be located at `libs/{jarName}` relative to the project root.
        </AstroTabItem>

        <AstroTabItem label="Gradle Kotlin DSL" icon="mdi:console">

            Add the local file dependency:

            <Code lang="kotlin" code={`
    dependencies {
        implementation(files("libs/${jarName}"))
    }`}
            />

            The JAR must be located at `libs/{jarName}` relative to the project root.

        </AstroTabItem>
    </AstroTabs>
</Steps>


## Choosing an installation method

For most PaperMC plugin projects, use the local Maven installation.

Advantages:

- standard Maven coordinates
- works with Maven and Gradle
- keeps dependency management clean
- avoids project-local binary files

The legacy `libs` approach is mainly useful for projects where the Reedwork JAR must remain directly inside the repository.

## Verify the installation

After adding Reedwork, your project should be able to import Reedwork classes:

<Code lang="java" code={`

`} />
