# Utilities

Reedwork provides a collection of small utility classes for common Paper and Minecraft development tasks.

Each utility focuses on one specific problem and can be used independently.

## Available utilities

| Utility                                      | Description                                                                                    |
|----------------------------------------------|------------------------------------------------------------------------------------------------|
| [BedrockUtils](./bedrock-utils/)             | Detect whether a player joined through Geyser/Floodgate.                                       |
| [BukkitToString](./bukkit-to-string/)        | Convert common Bukkit objects into compact, human-readable strings.                            |
| [ColorUtils](./color-utils/)                 | Generate gradients, extract colors, convert colors to hexadecimal, and generate random colors. |
| [ColorfulnessFinder](./colorfulness-finder/) | Select the two most colorful colors from a collection of Bukkit colors.                        |
