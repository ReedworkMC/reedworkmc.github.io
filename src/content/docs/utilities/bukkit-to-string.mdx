# BukkitToString

`BukkitToString` provides small formatting utilities for converting common Bukkit objects into readable strings.

It is useful for messages, command output, logging, debugging, and other situations where a Bukkit object needs to be represented as text.

The utility does not serialize objects into a reversible format. It produces compact, human-readable representations.

## Locations

Locations can be formatted either as block coordinates or with their exact coordinates and rotation.

### `formatLocation(Location location)`

Returns the world name and block coordinates:

<Code lang="java" code={`
String location = BukkitToString.formatLocation(player.getLocation());
`} />

Example output:

```text
world 120 64 -35
```

The X, Y, and Z values are obtained from the block coordinates of the location.

### `formatLocationDetailed(Location location)`

Returns the world, exact coordinates, yaw, and pitch:

<Code lang="java" code={`
String location = BukkitToString.formatLocationDetailed(player.getLocation());
`} />

Example output:

```text
world 120.5 64.0 -35.25 yaw:90.0 pitch:12.5
```

This format is useful when the exact position and player or entity rotation are relevant.

## Worlds

### `formatWorld(World world)`

Returns the world's name:

<Code lang="java" code={`
String worldName = BukkitToString.formatWorld(player.getWorld());
`} />

Example output:

```text
world
```

This is useful when a `World` needs to be represented as text.

## Vectors

### `formatVector(Vector vector)`

Formats a Bukkit `Vector` as three space-separated coordinates:

<Code lang="java" code={`
String vector = BukkitToString.formatVector(direction);
`} />

Example output:

```text
0.0 1.0 -1.0
```

## Blocks

### `formatBlock(Location location)`

Formats the block at a location together with its position:

<Code lang="java" code={`
String block = BukkitToString.formatBlock(player.getLocation());
`} />

Example output:

```text
STONE at world 120 64 -35
```

The block type is followed by the formatted block location.

## Materials

### `formatMaterial(Material material)`

Converts a Bukkit `Material` into its lowercase name:

<Code lang="java" code={`
String material = BukkitToString.formatMaterial(Material.DIAMOND_SWORD);
`} />

Example output:

```text
diamond_sword
```

This is useful when a Bukkit material should be displayed without the uppercase enum representation.

## Items

### `formatItem(ItemStack item)`

Formats an `ItemStack` using its amount and material:

<Code lang="java" code={`
String item = BukkitToString.formatItem(itemStack);
`} />

For a normal item, the output looks like:

```text
3x diamond
```

Air items and `null` values are represented as:

```text
air
```

This makes the method useful for empty inventory slots and other situations where an item may not exist.

## Entities

### `formatEntity(Entity entity)`

Formats an entity using its entity type and block location:

<Code lang="java" code={`
String entity = BukkitToString.formatEntity(entity);
`} />

Example output:

```text
zombie at world 120 64 -35
```

The entity type is converted to lowercase and combined with its formatted location.

## Players

### `formatPlayer(Player player)`

Formats a player using their name and block location:

<Code lang="java" code={`
String player = BukkitToString.formatPlayer(player);
`} />

Example output:

```text
Steve at world 120 64 -35
```

This is useful for compact player-related messages and logging.

## Rotation

### `formatRotation(Location location)`

Formats the yaw and pitch of a location:

<Code lang="java" code={`
String rotation = BukkitToString.formatRotation(player.getLocation());
`} />

Example output:

```text
yaw:90.0 pitch:12.5
```

Unlike `formatLocationDetailed`, this method only contains the rotation values.

**Returns:**

A string containing the world, exact coordinates, yaw, and pitch.

Formats a world using its Bukkit name.

**Parameters:**

| Parameter | Type | Description |

| Parameter | Type | Description |

## Summary

`BukkitToString` provides a consistent way to convert frequently used Bukkit objects into readable strings.

It is especially useful for:

- command feedback;
- player messages;
- logging;
- debugging;
- readable event output;
- displaying Bukkit objects without manually formatting their properties.

The methods only format selected Bukkit properties and do not perform object serialization.
